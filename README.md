🚀 **Day 03/30 – SOC Analyst Home Lab Journey | Authentication Log Analysis**

Continuing my 30-Day SOC Analyst Home Lab journey!

Today, I'm focusing on understanding authentication logs and learning how SOC Analysts investigate login activities to identify potentially suspicious behavior.

🎯 **Today's Learning Objectives:**

🔹 Understand authentication log structures.
🔹 Analyze login timestamps and usernames.
🔹 Identify source IP addresses.
🔹 Differentiate successful and failed login attempts.
🔹 Recognize suspicious authentication patterns.
🔹 Understand how authentication logs support security investigations.

🔬 **Hands-on Practical Activities:**

Today, I will work on:

✅ Exploring Linux authentication logs.
✅ Understanding `/var/log/auth.log`.
✅ Identifying failed SSH login attempts.
✅ Investigating successful login activities.
✅ Filtering authentication events using Linux commands.
✅ Analyzing login activity based on timestamps, usernames, and source IP addresses.
✅ Identifying repeated failed login attempts.
✅ Documenting suspicious authentication patterns.

💻 **Commands & Tools to Explore:**

• `cat` – Display log contents.
• `grep` – Search specific authentication events.
• `less` – Read logs page by page.
• `tail` – Monitor recent log entries.
• `awk` – Extract specific log fields.
• Linux Authentication Logs – Investigate login activities.

🛡️ **SOC Analyst Perspective:**

A series of failed login attempts followed by a successful login may indicate a possible brute-force attack or unauthorized access.

However, this pattern alone does not confirm an attack. A SOC Analyst must investigate additional evidence, including source IP addresses, timestamps, usernames, login patterns, and related security events.
